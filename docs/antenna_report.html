Section 01 — Overview
Project Overview

What was designed, and why it matters.

What is a 2×2 Array?

Instead of using one patch, we arrange four identical patches in a 2-row × 2-column grid and feed them all with equal power through a corporate T-junction feed network. The signals from all four patches add up in the forward direction — constructive interference — giving higher gain and a narrower, more focused beam.

Corporate T-Junction Feed Network

A corporate feed distributes RF power from the single input port equally to all four patches with equal amplitude and phase. Quarter-wave (λ/4) transformers at 70.7 Ω step the impedance at each T-junction — from 100 Ω branches down to the 50 Ω system impedance — ensuring all patches radiate simultaneously with identical excitation.

Calculations — Section 02
Patch Dimension Design

Step-by-step analytical equations → optimised in CST full-wave simulation.

1
Patch Width W — maximise radiation efficiency
Width is derived from the resonant condition of the radiating edges. Chosen to maximise radiation efficiency.
Patch Width Formula
W = (c / 2f₀) × √(2 / (εr + 1))
W = (3×10⁸ / 2×2.4×10⁹) × √(2 / (4.4 + 1))
W = 0.0625 × √(0.3704)
W = 0.0625 × 0.6086
W ≈ 38 mm → Optimised in CST: W = 55 mm
W = 55 mm
2
Effective Dielectric Constant ε_eff (Hammerstad-Jensen)
Fields fringe through BOTH air and substrate — ε_eff is the weighted effective permittivity.
Hammerstad-Jensen Formula
ε_eff = (εr+1)/2 + (εr−1)/2 × (1 + 12h/W)^(−½)
ε_eff = (4.4+1)/2 + (4.4−1)/2 × (1 + 12×1.6/55)^(−½)
ε_eff = 2.7 + 1.7 × (1.349)^(−½)
ε_eff = 2.7 + 1.7 × 0.8607
ε_eff = 4.163
ε_eff = 4.163
3
Fringing Length Extension ΔL
E-field extends slightly beyond physical patch edges — patch appears electrically longer. Subtract 2ΔL to get correct physical length.
Hammerstad Fringing Correction
ΔL = 0.412h × [(ε_eff+0.3)(W/h+0.264)] / [(ε_eff−0.258)(W/h+0.8)]
ΔL = 0.412×1.6 × [(4.163+0.3)(34.375+0.264)] / [(4.163−0.258)(34.375+0.8)]
ΔL = 0.659 × [4.463 × 34.639] / [3.905 × 35.175]
ΔL = 0.659 × 154.59 / 137.36
ΔL = 0.741 mm
ΔL = 0.741 mm
4
Patch Length L — half-wave resonance minus fringing
Patch Length
L_eff = c / (2 × f₀ × √ε_eff)
L_eff = 3×10⁸ / (2×2.4×10⁹ × √4.163)
L_eff = 3×10⁸ / (4.8×10⁹ × 2.040) = 30.6 mm

L = L_eff − 2ΔL = 30.6 − 2×0.741 = 30.6 − 1.48
L = 29.1 mm → Optimised in CST: L = 39.8 mm
💡 Why does optimised length differ? The analytical formula uses a simplified transmission-line model. The actual patch is part of a corporate feed network with inset cuts, in an array environment — all these effects shift resonance. CST full-wave simulation captures all interactions, so optimised dimensions are more accurate.
L = 39.8 mm
5
Inset Feed Depth y₀ — transforms 200 Ω edge → 50 Ω
The patch edge impedance is ~200 Ω. The feed line is 50 Ω. Moving the feed point inward reduces the local impedance to match 50 Ω — no external matching network needed.
Inset Impedance Formula
Z_in(y₀) = Z_edge × cos²(π × y₀ / L)

For 50 Ω matching:
y₀ = (L/π) × cos⁻¹(√(50 / Z_edge))

Design values: gap = 1.5 mm , inset y₀ = 8.0 mm
y₀ = 8 mm → 50 Ω match

Calculations — Section 03 & 04
S11 & VSWR Math

Full reflection coefficient derivation, power analysis and VSWR verification.

S11 = 20 × log₁₀|Γ|  ·  Rule: S11 < −10 dB = Acceptable  |  < −15 dB = Good  |  < −20 dB = Excellent
1
|Γ| from resonance — S11 = −34 dB
Reflection Coefficient at Resonance
|Γ| = 10^(S11/20) = 10^(−34/20) = 10^(−1.7)
|Γ| = 0.0200

Reflected power = |Γ|² × 100 = (0.020)² × 100 = 0.04% — almost zero!
Only 0.04% reflected at resonance
2
VSWR at 2.4 GHz marker (S11 = −18.96 dB)
VSWR Calculation
|Γ| = 10^(−18.96/20) = 10^(−0.948) = 0.1124

VSWR = (1 + |Γ|) / (1 − |Γ|)
VSWR = (1 + 0.1124) / (1 − 0.1124)
VSWR = 1.1124 / 0.8876 = 1.25 ✓ (threshold < 2.0)
VSWR = 1.25 ✓ Excellent
3
Power Budget — radiated vs reflected
Power Analysis
Reflected power = |Γ|² × 100 = (0.1124)² × 100 = 1.26%
Radiated power = 100 − 1.26 = 98.74%

Safe continuous TX power: 7–8 W | Short burst: 12–15 W
98.74% of input power is radiated
4
Cross-check: |Γ| from VSWR → S11
Cross-Verification
Γ = (VSWR − 1) / (VSWR + 1) = (1.25 − 1) / (1.25 + 1) = 0.25 / 2.25
Γ = 0.1111
S11 = 20×log₁₀(0.1111) = −19.08 dB ✓ (matches marker −18.96 dB)
Cross-check passed ✓ — both routes agree

Bandwidth & Power Handling

−10 dB impedance bandwidth from S11 curve + copper thermal power limit.

1
Bandwidth — −10 dB criterion
Read the two frequencies where S11 = −10 dB on the curve, then subtract to get bandwidth.
Bandwidth Calculation
f₁ (lower −10 dB crossing) = 2.355 GHz
f₂ (upper −10 dB crossing) = 2.445 GHz

BW = f₂ − f₁ = 2.445 − 2.355 = 0.090 GHz = 90 MHz

% BW = (BW / f₀) × 100 = (90 / 2400) × 100 = 3.75%
BW = 90 MHz (3.75%) — full WiFi coverage ✓

2
Dielectric Breakdown Power (theoretical ceiling)
E-field scales as √P. Find the power needed to reach FR4's breakdown field of 20 MV/m.
Dielectric Breakdown Power
Maximum E-field from CST @ 1 W input: E_sim = 12,593.9 V/m
FR4 dielectric breakdown field: E_breakdown = 20,000,000 V/m

P_max = P_sim × (E_breakdown / E_sim)²
P_max = 1 × (20,000,000 / 12,593.9)²
P_max = 1 × (1588.1)² = 2.52 MW (theoretical)
⚠️ This 2.52 MW figure is purely theoretical — the PCB would burn long before electrical breakdown. The real limit is thermal (next step).
3
Copper Thermal Limit — actual safe power
Skin effect concentrates current at conductor edges. RF derating factor = 2.5 applied.
Thermal Power Limit
Feed line: width = 3.1 mm, copper thickness = 35 µm
P_copper = I² × R_feed = 0.7656 × 25 = 19.14 W (DC limit)

RF derated = 19.14 / 2.5 = 7.66 W
Safe continuous = 7–8 W | Short burst = 12–15 W
Real limit: 7–8 W continuous | 12–15 W burst

Calculations — Section 07
Gain & Efficiency

Converting CST dB output to %, realized gain, and array gain formula verification.

Directivity = beam focus assuming 100% efficiency. Gain = D × η_rad. Realized Gain = Gain × (1 − |Γ|²), also accounting for impedance mismatch loss. All measured in dBi (dB relative to an isotropic radiator).
1
Radiation Efficiency — dB to percentage
CST reports −0.4384 dB. Convert to percentage to understand physical loss in substrate and conductor.
Radiation Efficiency Conversion
η_rad = 10^(−0.4384/10) = 10^(−0.04384)
η_rad = 0.9022 = 90.22%

Loss = 9.78% → heat dissipated in FR4 dielectric + copper conductor resistance
Radiation Efficiency = 90.22%
2
Total Efficiency — includes mismatch loss
Total Efficiency
η_tot = 10^(−0.4940/10) = 10^(−0.0494)
η_tot = 0.8907 = 89.07%

Mismatch loss = η_tot / η_rad = 89.07 / 90.22 = 98.7% (very small, as expected for VSWR=1.25)
Total Efficiency = 89.07%
3
Realized Gain
Realized Gain (includes both losses)
G_realized = Directivity + Total_Efficiency (in dB)
G_realized = 10.11 + (−0.4940)
G_realized = 9.62 dBi
Realized Gain = 9.62 dBi
4
Array Gain Formula — N = 4 elements
Theoretical gain from combining identical, in-phase, equally-spaced elements.
Array Gain Formula
G_array = G_single + 10 × log₁₀(N)
G_array = 7.0 + 10 × log₁₀(4)
G_array = 7.0 + 10 × 0.602 = 7.0 + 6.02 = 13.02 dBi (ideal)

Simulated: 10.11 dBi — difference of 2.91 dB due to:
→ Mutual coupling between elements
→ Substrate dielectric losses (FR4 tan δ = 0.02)
→ Feed network insertion loss
+3.11 dB gain improvement over single patch (2× power)

Smith Chart Verification

Full analytical derivation of |Γ| from complex impedance — verified against CST simulation.

Smith Chart centre = 50 + j0 Ω (perfect match). At 2.4 GHz: Z_L = 54.2 − j11 Ω. We compute |Γ| analytically and verify it matches the simulated S11 marker of −18.96 dB.
1
Set up Γ = (Z_L − Z₀) / (Z_L + Z₀) with Z₀ = 50 Ω
Z_L = 54.2 − j11 Ω , Z₀ = 50 Ω

Numerator: (54.2 − j11) − 50 = 4.2 − j11
Denominator: (54.2 − j11) + 50 = 104.2 − j11
2
Compute magnitudes — |a + jb| = √(a² + b²)
|numerator| = √(4.2² + 11²) = √(17.64 + 121) = √138.64 = 11.775
|denominator| = √(104.2² + 11²) = √(10857.6 + 121) = √10978.6 = 104.78
3
Final |Γ| and S11
|Γ| = |numerator| / |denominator| = 11.775 / 104.78 = 0.1124

S11 = 20 × log₁₀(0.1124) = 20 × (−0.9492) = −18.99 dB

Simulated S11 at 2.4 GHz marker = −18.96 dB → matches! ✓
